# «Омӯзгори ҳушманд — AI Ёвар» (Smart Teacher — AI Assistant)

Платформаи воқеии инноватсионии маорифи рақамӣ дар заминаи зеҳни сунъии Google Gemini API барои муассисаҳои таҳсилоти умумии Ҷумҳурии Тоҷикистон.

**Озмуни ҷумҳуриявӣ:** «Идеяи ман — калиди фардо»  
**Самти лоиҳа:** Зеҳни сунъӣ, технологияҳои иттилоотӣ, маориф ва омӯзиши рақамӣ  
**Муаллифи лоиҳа:** Ярахмадов Аличон, хонандаи синфи 11 «г»-и МТМУ №36-и ноҳияи Шоҳмансури шаҳри Душанбе  
**Муассисаи пешниҳодкунанда:** Муассисаи таҳсилоти миёнаи умумии №36-и шаҳри Душанбе  
**Забони асосӣ:** Тоҷикӣ (бо дастгирии русӣ ва англисӣ)  

---

## 1. Ҳуҷҷати расмии лоиҳа

### 1.1. Аннотатсия
Лоиҳаи мазкур ба таҳия ва ҷорисозии як платформаи амалкунандаи зеҳни сунъӣ барои низоми таҳсилоти миёнаи умумии Ҷумҳурии Тоҷикистон бахшида шудааст. Барнома бар пояи модели муосири Google Gemini 3.8 Flash SDK сохта шуда, бо таҳлили амиқи методикаи миллии таълим барои омӯзгорон (таҳияи худкори нақшаи дарс бо 14 марҳила, сохтани тестҳои 4-варианта, саволҳои шифоҳӣ ва арзёбии ҷавобҳо) ва хонандагон (тавзеҳи қадам ба қадами масъалаҳои риёзӣ, физикӣ, химия ва забону адабиёт) хизмат мерасонад.

### 1.2. Муқаддима ва Мубрамияти мавзӯъ
Дар партави дастуру супоришҳои Асосгузори сулҳу ваҳдати миллӣ — Пешвои миллат, Президенти Ҷумҳурии Тоҷикистон муҳтарам Эмомалӣ Раҳмон оид ба «Бистсолаи омӯзиш ва рушди фанҳои табиатшиносӣ, дақиқ ва риёзӣ дар соҳаи илму маориф (солҳои 2020-2040)», татбиқи технологияҳои рақамӣ аҳамияти аввалиндараҷа пайдо намудааст. Омӯзгорон соатҳои зиёди вақти худро сарфи корҳои такроршавандаи коғазӣ мекунанд ва хонандагон ҳангоми иҷрои вазифаи хонагӣ ба роҳнамои инфиродӣ ниёз доранд. «Омӯзгори ҳушманд» ин масъаларо бо истифодаи зеҳни сунъӣ комилан ҳал менамояд.

### 1.3. Ҳадаф ва Вазифаҳо
* **Ҳадаф:** Эҷоди ёвари рақамии ҳамаҷониба ба забони тоҷикӣ барои сабук кардани кори омӯзгор ва баланд бардоштани савияи дониши хонандагон.
* **Вазифаҳо:**
  1. Худкоркунии таҳияи нақшаи расмии дарсҳо тибқи меъёрҳои Вазорати маориф ва илми ҶТ.
  2. Тавлиди тестҳои 4-вариантаи интерактивӣ бо ҳисоби худкори хол ва тавзеҳи хатоҳо.
  3. Фароҳам овардани муҳити ҳалли қадам ба қадами масъалаҳои риёзӣ барои хонандагон.
  4. Таъмини амнияти комил (нигоҳдории калиди API танҳо дар сервер).

## 2. Меъмории техникӣ ва Амният

* **Фронтенд:** React 19, TypeScript, Tailwind CSS, Lucide Icons.
* **Бекенд:** Node.js, Express, TypeScript (tsx).
* **Зеҳни сунъӣ:** Китобхонаи расмии `@google/genai` (модели `gemini-3.8-flash`).
* **Амният:** Калиди `GEMINI_API_KEY` танҳо дар қисми серверии `server.ts` истифода мешавад ва ҳеҷ гоҳ ба клиент ё браузер намебарояд.
* **Нигоҳдории маҳаллӣ:** Бақайдгирии корбарон бо рақамҳои муътабари тоҷикии `+992`, нигоҳдории нақшаҳо, тестҳо ва таърихи чат дар `localStorage`.

## 3. Имкониятҳои асосӣ

### Бахши омӯзгор («Ёвари омӯзгор»)
1. **Нақшаи дарс:** Таҳияи худкори план-конспекти яксоата бо ҳамаи 14 банди ҳатмӣ (мақсадҳои таълимӣ, тарбиявӣ, инкишофдиҳанда, натиҷаҳои интизоршаванда, 8 давраи ҷараёни дарс).
2. **Сохтани тест:** Тестҳои 4-варианта (А, Б, В, Г) бо сабти калидҳои пинҳонӣ, интерфейси супоридани тест ва баҳодиҳии автоматӣ.
3. **Саволҳои шифоҳӣ:** Гурӯҳбандии саволҳо аз рӯйи 3 сатҳ: Осон (репродуктивӣ), Миёна (татбиқӣ) ва Мураккаб (эҷодӣ).
4. **Маводи таълимӣ:** Конспект, маърӯза, презентатсияи слайд ба слайд, варақаҳои супоришӣ, матни диктант, ҷадвалҳои муқоисавӣ ва машқҳо барои хонандагони сустхон ва болаёқат.
5. **Арзёбии ҷавоби хонанда:** Таҳлили ҷавоби хонанда бо нишон додани ҷиҳатҳои қавӣ, хатоҳо, тавсияҳо ва баҳои тавсиявӣ.

### Бахши хонанда («Ёвари хонанда»)
1. **Тавзеҳи содаи мавзӯъ:** Шарҳи мавзӯъҳои душвор бо мисолҳои рӯзмарраи ҳаётӣ.
2. **Ҳалли қадам ба қадами математика:** Нишон додани формулаҳо, дискриминант, теоремаи Виет ва мантиқи ҳал.
3. **Қонуну формулаҳо (Физика ва Химия):** Тавзеҳи қонунҳо, воҳидҳои ченаки СИ ва таҷрибаҳо.
4. **Забон ва Адабиёт:** Таҳлили шеърҳо, қоидаҳои синтаксисӣ ва имлои забони тоҷикӣ.
5. **Омодагӣ ба имтиҳон:** Нақшаи такрори мавзӯъ ва тестҳои худсанҷӣ.

### Чати зеҳни сунъӣ
Муоширати мустақим бо Gemini API бо интихоби фан, синф ва забон, нусхабардорӣ ва имконияти фиристодани дубора.

### Ҷадвали ҳафтаина
Банақшагирии соатҳои таълимӣ барои рӯзҳои Душанбе то Шанбе бо синфхона ва замони дарс.

## 5. 15 Саволу Ҷавоби Ҳакамон

1. **Фарқият аз ChatGPT?** — Мутобиқат бо 14 марҳилаи таълимии Тоҷикистон ва қолаби дидактикии миллии 20 фан.
2. **Бехатарии калид?** — Калид танҳо дар сервери Node.js аст, ба браузер фиристода намешавад.
3. **Агар AI хато кунад?** — Маводҳо тавсиявианд ва қарори ниҳоӣ бо омӯзгор аст.
4. **Арзиши татбиқ?** — Хароҷоти ибтидоӣ қариб сифр аст (Free tier ва муҳити абрии сарфакор).
5. **Чаро телефони +992?** — Барои сохтани пойгоҳи муътабари омӯзгорону хонандагони Тоҷикистон.
6. **Оё дар телефон кор мекунад?** — Бале, тарҳи веб-барнома барои ҳамаи экранҳо (iPhone, Android, планшет, PC) мутобиқ аст.
7. **Имкони чоп?** — Бале, тугмаи махсуси чопи расмӣ мавҷуд аст.
8. **Ҳалли қадам ба қадам?** — AI формулаҳо ва пайдарпайии ҳалро пурра нишон медиҳад.
9. **Фанҳои дигар?** — Ҳамаи 20 фанни мактабӣ ва имконияти навиштани фанни дилхоҳ вуҷуд дорад.
10. **Саҳми муаллиф?** — Муаллиф (хонандаи синфи 11) тамоми барномасозӣ, логикаи методӣ ва пайвасти API-ро анҷом додааст.
11. **Ҳисоби холҳо чӣ гуна сурат мегирад?** — Ба таври худкор аз рӯйи калиди дохилии тести тавлидшуда.
12. **Кадом модели AI истифода мешавад?** — Google Gemini 3.8 Flash тавассути `@google/genai` SDK.
13. **Таърихи корбар дар куҷо сабт мешавад?** — Дар хотираи браузери корбар (localStorage).
14. **Барои мусобиқа кадом сенария омода аст?** — Сенарияи 4-марҳилаи Алгебра (Муодилаҳои квадратӣ), Физика, Забони тоҷикӣ ва IT.
15. **Нақшаи оянда?** — Бастабандӣ ба замимаи мобилӣ ва пайваст кардани овози тоҷикӣ.

## 6. Дастури насб ва оғоз

```bash
# 1. Насби вобастагиҳо
npm install

# 2. Танзими калиди муҳит
# Дар файли .env калиди худро гузоред:
GEMINI_API_KEY="КАЛИДИ_ШУМО"

# 3. Оғози сервери барнома
npm run dev

# 4. Сохтани лоиҳа барои нашр
npm run build
```
